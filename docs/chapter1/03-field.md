# Field

A field \\( \mathbb{F} \\) is

- A set contains at least 0 and 1
- \\( a + b = b + a, \quad \forall a,b \in \mathbb{F} \\)
- \\( (a + b) + c = a + (b + c), \quad \forall a,b,c \in \mathbb{F} \\)
- \\( (ab)c = a(bc), \quad \forall a,b,c \in \mathbb{F} \\)
- \\( a + 0 = a, \quad \forall a \in \mathbb{F} \\)
- \\( a1 = a, \quad \forall a \in \mathbb{F} \\)
- \\( \forall a \in \mathbb{F}, \exists (-a) \in \mathbb{F}: a + (-a) = 0 \\)
- \\( \forall a \in \mathbb{F}, a \neq 0,
  \exists (1/a) \in \mathbb{F}: a (1/a) = 1 \\)
- \\( a(b + c) = ab + ac, \quad \forall a,b,c \in \mathbb{F} \\)
